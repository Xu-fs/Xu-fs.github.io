# Action 页面内容

这个页面会读取本文件的两个 Markdown 表格。每新增一行，刷新页面即可生成新的液态玻璃卡片。

详情文章请放入 `articles/` 文件夹，并在详情文章列填写相对路径。卡片图片放在 `images/` 文件夹，在图片路径列填写相对路径；不填写时会使用默认图片位置。
